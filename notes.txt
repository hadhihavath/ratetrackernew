## Cuelinks API Research Findings

### What Cuelinks DOES Provide:
- **Campaigns API** (`/campaigns?q=`) - Search merchant campaigns
- **Link Conversion** (`/links/convert`) - Convert merchant URLs to affiliate tracking links
- **Offers/Deals** (`/offers`) - Live coupon codes and promotional offers
- **Performance Reports** (`/reports/performance`) - Earnings/commission tracking
- **Smart Redirector** - `https://linksredirect.com/?cid=82192&source=api&url=...`

### What Cuelinks DOES NOT Provide:
- ❌ Direct product pricing data
- ❌ Product catalogs or search APIs
- ❌ Real-time price comparison across merchants
- ❌ Product specifications or images

### Integration Pattern Used:
1. Server-side proxy (`/api/cuelinks`) keeps API key secure
2. Client generates affiliate links via `generateCuelinksUrl()`
3. Fail-safe fallback to direct store links if ad-blockers intercept
4. Real Cuelinks campaigns displayed in "Price Drop" section

## Notes on Cuelinks API Usage for Price Comparison

Since Cuelinks doesn't provide product pricing directly, the current approach:
1. **Approved Merchant Feeds** - Direct API integrations with each merchant
2. **Normalized Cache** - Server-side aggregation in `lib/merchantFeeds.js`
3. **Supabase Storage** - Persistent product/price database
4. **Cuelinks Only For** - Affiliate link conversion + live deals/offers

Future: Consider integrating with:
- Datafeedr API (product data + prices)
- Keepa API (Amazon price history)
- Custom scrapers (with proper authorization)
